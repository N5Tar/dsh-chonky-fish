# 连续语音实施自审与独立复查

日期：2026-11-14。设计与集成由主代理负责；代码由用户指定的 Luna high 执行，独立只读复查由 Luna xhigh 执行。以下为实际修改与测试的结果，不代替最终运行验收；运行进度见[验收记录](voice-call-validation-2026-11-14.md)。

最终界面依据[单按钮设计 v3](windows-voice-call-design-v3.md)：语音只保留 composer 发送按钮旁的一个按钮。旧通话条、设置、重播和待处理面板已经移除，应用级控制器继续独立于页面生命周期。

2026-11-15 后续修订：模型闲置回收后的再次开启会刷新能力并自动准备，能力错误分项提示，修复 Shadow DOM 内按钮图标。新构建、回归及三条实际语音证据见[排查与修复记录](voice-call-fix-2026-11-15.md)；下方固定摘要保留为 11 月 14 日验收产物记录。

同日曾实施[非通话自动播报](voice-reply-auto-play-design.md)，用户随后明确纠正，该产品入口已撤回；此前测试只保留为历史，不代表当前要求。最新[设计 v4](windows-voice-call-design-v4.md)和[技术 v3](voice-call-technical-v3.md)进一步明确插入、后台任务与扬声器打断，实施状态独立列明。

## 复查范围与修订

| 范围 | 实际发现与修订 |
| --- | --- |
| 插件启动 | 可选 Speech Remote 必须在 Cordis 注入作用域内取得；缺少语音扩展时保留正常插件界面，能力检查失败被通话界面捕获 |
| 打包与浏览器资源 | Worker / Worklet 路径与模型资源目录分别映射；长度、摘要、MIME 和固定键校验；缓存已验证字节，不能按旧摘要发送被替换的文件 |
| VAD 实际运行 | 真实浏览器发现 ORT UMD 与 Worker 全局变量冲突，已修复并补实际固定 UMD 的加载回归；模型采用 v5 的 64 样本上下文、512 样本窗口、串行有界推理 |
| 音频生命周期 | 迟到权限不能复活旧通话；重开等待旧媒体清理；输出音频在播放失败、取消、迟到合成路径均释放 |
| 持续扬声器对话 | 真实首轮发现 gate 期间错误触发两秒采样 watchdog；改为持续观测 PCM 到达而丢弃 gated 内容，补超两秒播报与真正停采回归 |
| 输入顺序与接收证据 | 接收不可被迟到网络错误回退；unknown 不自动重发；显式重发使用新身份；inbox 移除解除旧输入阻塞；队列与音频总预算跨通话保留 |
| 键盘与来源 | 本地键盘接收推进播报代次；事件先于或晚于回执均保留证明；结果不明维持有界关联；历史、外部、混合来源不误播 |
| 会话重置 | 重置屏障先等待音轨、播放和租约清理，再切换会话；保留同一服务、旧输入和最长 30 秒核对，不在普通 reset 中直接 dispose |
| 跨通话异步竞态 | 回复绑定原 run；旧 turn 完成、迟到合成、播放完成及尾音计时均不能播放或修改新通话；旧音频仍须释放，旧接收证明仍能核对 |
| 模型执行失败 | 真实桌面发现已接收输入因缺少模型凭据执行失败；保留 accepted，显示具体失败和修复指导，不提供编辑、丢弃或重复发送按钮 |
| 桌面菜单交互 | 旧通话条曾挡住模型菜单且无法折叠，已完成问题验证；最终按用户要求移除通话条与设置层，语音按钮直接跟随现有 composer 布局 |
| 单按钮错误恢复 | 隐藏待处理面板会使八次失败后无法清理预算；显式 End/reset 启用 `abandonPending`，释放本地音频，未知结果保留有界身份和短期核对，新通话不补发旧输入 |
| 同会话重叠通话 | 按通话 scopeId 区分引用、观察记录及提交，不使用 DTO 对象地址；旧新通话可任意顺序释放，旧事件不能被新通话当作本地键盘输入 |
| 核心 / 适配集成 | 增加真实核心加真实 DSH 适配器的一轮集成替身测试，验证复制后的 ConversationRef、投递、消费事件及回复归属，而非只用同一对象调用适配器 |

构建时间晚于最后的核心修订。完整 `test:voice` 通过：核心 6 组、服务 33 组、共享音频 7 组，以及 Speech、Conversation（含核心 / 适配集成）、Host HTTP、真实 Windows TTS、生成 Client 无界面启动、重置顺序、bootstrap 订阅等待、冷启动准备 / 取消和单按钮生命周期测试。Silero 真实 WASM 语音正向样本测试另行通过。资源与平台回归分别为 19 / 19 和 8 / 8。

独立复查逐项确认上述代码修订，最终窄范围复查未发现剩余代码阻塞项。它不等于已通过未执行的休眠、硬件拔插、所有蓝牙设备或任意回声场景。扬声器全双工继续关闭，首版使用自动轮流说话；耳机模式支持插话停播。

构建或插件更新会触发 DSH 热重载，并按卸载流程结束通话。稳定运行验收必须冻结源码和生成产物，不在计时期间重新构建。全项目已有 Windows 测试限制见[验收记录](voice-call-validation-2026-11-14.md)。
