# 行动模式 V1 · 星露谷陪玩

用户说“来，一起玩星露谷”，大肥鱼以一个可见的同伴角色加入当前农场。邀请本身就足以开始。即使用户没有分工，大肥鱼也能根据周围的情况和自己的兴趣选择当天的第一件事，并在合适的时候主动聊天。

## 一起浇地

大肥鱼看到用户在田地左边浇水，右边还有几块干地。它可以说“右边我来”，选一块干地走过去。抵达后再看一眼，如果用户已经浇过，就换下一块。它可以安静地完成接下来的工作。用户说“走，去钓鱼”时，它放下剩余的浇地计划，按新意图行动。如果用户只是离开田边，它可以继续浇地，也可以问一句对方要去哪里。

## 从观察到行动

- **进入。** 首版建议从用户邀请开始。连接游戏后，确认当前存档可用，找到或生成属于大肥鱼的同伴，并确认后续指令指向这个角色。
- **观察。** 游戏接入层读取最新的角色、周围地块和用户状态。连续更新的观察可以合并。决策同时参考眼前的变化、当前打算、执行中的动作和最近的对话。ABS 提供自身状态，行动模式负责在游戏过程中触发下一次判断。
- **执行。** 大肥鱼选择目标，模组执行寻路和工具操作。指令入队只表示已经提交。以新的位置、地块状态或动作结果判断是否完成。等待期间仍然接收用户的话和场景变化。
- **继续。** 动作完成或失败、用户开口、相关局势变化都可以触发下一步。空闲时定期重新观察，给大肥鱼自己发起活动的机会。一次判断可以产生行动、聊天、两者兼有，或继续等待。
- **中断。** 收到新分工后，丢弃与之冲突的待执行步骤。对于已提交的动作，根据模组实际支持的取消能力处理，并在下一步前核对角色状态。用户结束陪玩、存档关闭或连接中断时停止发出指令。迟到的决策结果不能让已经结束的陪玩重新开始。

## 主动聊天

由同一个大肥鱼结合游戏和对话决定是否开口。例如认领一项工作、回应用户刚做的事、分享自己的发现，或提议接下来一起做什么。记住最近说过的话以及对方是否回应，避免逐格播报、重复提问。没有用户指令时也可以主动发起第一句话。首版建议文字交流，实机确认游戏内消息的收发能力；用户从大肥鱼现有会话说的话也应能改变当前计划。

## 星露谷接入与待验证项

采用上游的可见同伴与隐藏 Farmer，通过 player 模式读取同伴周边并控制其移动和工具使用。将这些游戏细节放在星露谷接入层，行动模式只负责持续观察、决策、对话和停止这一轮陪玩。[StardewValley-MCP](https://github.com/amarisaster/StardewValley-MCP#companion-system)

首次联调需要确认角色绑定、观察更新延迟、指令结果能否对应到具体动作、行走途中能否取消，以及用户在游戏内发言能否被读取。上述行为属于设计目标，实时响应的具体时限以实机测量为依据。

## 一个游戏日的验收

1. 只说“来玩”，随后正常游戏。大肥鱼出现在农场，即使没有进一步分工也能自行选事并开始行动。
2. 在它抵达目标前，用户先浇完那块地。大肥鱼能根据新状态换目标。
3. 陪玩期间能观察到大肥鱼主动发起与当下有关的聊天。一次交谈结束后，它仍能继续做事。
4. 在浇地途中改口说“跟我走”。观察它何时收到消息、何时改变行动，以及是否误发旧计划的后续指令。
5. 结束陪玩后，确认没有新动作或聊天发出。重新进入时，以当前存档和角色状态开始判断。
