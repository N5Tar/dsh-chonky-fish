# 大肥鱼资料导入 / 导出方案 V1

- 日期：2026-11-11
- 状态：V1 已实现基础代码与离线回归测试；尚未进行当前 DSH GUI / 真实跨电脑验收
- 定位：迁移养成资料，不迁移运行环境
- 技术落地：[架构、模块、功能与菜单方案](<data-migration-technical-v1.md>)

## 1. 目标

用户在旧电脑导出一个资料包，在另一台已安装 DSH 和大肥鱼的电脑上选择该文件，一次确认完成恢复。

只迁移五类内容：

1. 身份与人格
2. 钱包与账本
3. 日记
4. 活动技能库
5. 通用偏好

不做完整环境搬家，不依赖 DSH 会话导入能力，不做云同步或多设备同步。

## 2. 迁移范围

| 类别 | 包含内容 | 恢复规则 |
|---|---|---|
| 身份与人格 | 名字、用户补充人格、默认个人资料目录中的正文文件 | 保留正文；个人资料定位到目标电脑默认目录 |
| 钱包与账本 | 当前余额、完整收支记录 | 整体替换，不累加、不重新计算历史交易 |
| 日记 | 全部日记日期与 Markdown 正文 | 整体替换，正文原样保留 |
| 活动技能库 | 技能信息、指南、经验、完整版本历史及修订信息 | 整库替换，保留历史，不创建额外修订 |
| 通用偏好 | 支持迁移的模块配置、休息时段、时间倍率等 | 按明确字段白名单校验、恢复 |

### 2.1 身份与人格

- 导出用户数据，不导出插件内置人格模板或预设代码。
- 默认个人资料目录内的普通资料文件纳入导出；拒绝符号链接等特殊条目，不沿链接读取外部文件。顶层 `browser-profile` 运行目录明确排除，避免带走浏览器登录态、缓存和数据库文件。
- 不携带源电脑的个人资料绝对路径。
- 自定义外部个人资料目录不自动打包。导出摘要应明确提示未包含该目录；用户需要时先将资料放入默认个人资料目录。
- 导入后将个人资料目录设置为目标电脑默认目录。
- 正文中出现的历史路径原样保留，不进行全文替换。

### 2.2 通用偏好

通用偏好不包含授权、连接状态或任务执行状态。

- 按字段白名单导出，不直接复制整个配置对象。
- 普通功能偏好、休息时段、时间倍率等可以恢复。
- 活动采集授权、主动投递启用状态不随资料包开启；导入后相关自动行为保持关闭或安全模式，由用户另行启用。
- ABS 可以迁移配置，不迁移满足度、时间锚点、去重记录、反馈历史等运行状态。
- 实现时在代码中维护唯一的可迁移字段白名单，导出、导入与测试共用；新增配置默认不迁移，明确纳入白名单后才迁移。

### 2.3 明确不迁移

- DSH 聊天记录、会话与附件。
- 语义事件记忆、事件抽取任务和进度。
- 小鱼塘工作区文件。
- ABS 运行状态和审计记录。
- 社交连接、主人绑定、收件箱、发送记录与凭证。
- DSH 定时任务。
- 电脑活动感知历史。
- 模型配置、API Key、浏览器登录态和系统权限。
- 主动消息会话绑定、运行计数和发送记录。
- 演示对话、浏览器缓存、临时文件和插件安装产物。

## 3. 用户流程

在设置中增加「资料导入 / 导出」入口，提供两个按钮，不做逐条勾选或复杂模式切换。

### 3.1 导出资料

1. 用户点击「导出资料」。
2. 系统读取五类资料，校验有效性并生成一致快照。
3. 展示资料数量、大小和排除项提示，特别说明自定义外部个人资料目录不包含在内。
4. 生成一个 `.fishpack` 文件供用户保存。

导出不删除或修改现有资料，不自动执行技能，不调用模型。

提示：资料包可能包含人格、日记和个人资料等隐私内容，请妥善保管。V1 不设计独立的密码加密与凭证迁移流程。

### 3.2 导入资料

1. 用户点击「导入资料」并选择 `.fishpack` 文件。
2. 系统先完成解包、格式、版本、大小和内容校验，不修改现有数据。
3. 展示资料摘要与替换提示。
4. 用户确认后，系统备份目标电脑现有的五类资料。
5. 在安全写入边界整体替换五类资料，刷新相关服务与界面。
6. 展示完成结果及备份位置；需要重启才能生效的配置明确提示重启。

确认文案：

> 将替换当前的身份与人格、钱包与账本、日记、活动技能库和通用偏好。系统会先备份现有资料。聊天、工作区、社交和其他数据不受影响。

自动行为安全提示：

> 导入不会自动启用电脑活动采集或主动投递，请按需重新开启。

## 4. 数据替换规则

### 4.1 整份替换，不做合并

- 五类内容作为一个恢复单元，不提供钱包累加、日记合并或技能同 ID 合并。
- 包内日记或技能库为空，表示将对应目标集合替换为空；摘要必须显示数量。
- 必需分类缺失属于非法包，不等同于空集合。
- 同一个包重复导入，五类资料结果一致，不增加余额、不复制账本、不追加技能版本。
- 身份与钱包共享底层状态文件时，仅替换对应白名单字段，保留文件中不属于本方案的字段。
- 通用配置同样只替换白名单字段；安全模式处理除外，不能用整个文件覆盖其他模块配置。
- 不修改五类范围之外的数据，也不自动清理目标电脑原有会话、事件和工作区。

### 4.2 备份与失败恢复

- 备份只覆盖本次可能修改的数据和字段，保存导入前的完整恢复信息。
- 备份失败时终止导入。
- 正式写入前先在暂存区准备全部内容。
- 写入失败时回滚本次涉及的全部资料，不能只恢复其中一类。
- 通过简单持久化事务标记记录准备、提交与完成阶段；若中途退出，启动时检测未完成导入并恢复，不能把半成品当作成功结果。
- 备份放在独立备份目录，不能被下一次导出递归收入。

## 5. 迁移包格式

采用 ZIP 容器，使用 `.fishpack` 扩展名。以下为建议布局，具体文件名在实现时固定：

```text
manifest.json
identity.json
wallet.json
preferences.json
profile/
diaries/
skills/
```

清单至少包含：

- 格式标识与迁移格式版本。
- 来源插件版本和导出时间。
- 五类资料的条目数。
- 文件列表、解压后大小与 SHA-256 摘要。
- 导出排除项提示，例如未包含自定义外部个人资料目录。

约束：

- 清单必须声明全部五类内容；允许显式空集合。
- 清单只使用包内相对路径，不保存源电脑绝对路径。
- 文件摘要用于检查完整性，不代表存档可信或经过签名。
- 活动技能复用现有单技能存档结构与校验逻辑，包级恢复负责整库替换；不直接循环调用现有拒绝同 ID 的单技能导入接口实现覆盖。
- 不打包整个大肥鱼 home，也不依赖宿主数据库或会话格式。

## 6. 必要实现约束

### 6.1 一致性与并发

导出和导入需要一个覆盖相关模块写入的短时维护边界：

- 导出期间获得一致快照，避免钱包余额与账本来自不同时间。
- 导入期间阻止五类资料的并发写入，包括后台工具写入，而不只是禁用界面按钮。
- 提交前重新检查目标资料是否变化；不能用较早的预览或备份覆盖确认期间的新写入。
- 完成后清理维护状态，并刷新相关缓存，防止旧缓存重新写回。

V1 不需要暂停整个宿主或迁移正在执行的任务。无法取得安全写入边界时，明确提示稍后重试。

### 6.2 校验与安全

- 严格验证迁移格式版本；未知的新版本拒绝导入并提示升级，不静默丢弃字段。
- 严格验证每类业务数据，不能使用「损坏就恢复默认值」的普通读取降级逻辑。
- 拒绝路径穿越、绝对路径、符号链接、硬链接、重复条目、大小写冲突等不安全或跨平台不可确定的路径。
- 对压缩包大小、解压后总大小、文件数、单文件大小和压缩比设定上限；具体数值在实现时统一定义。
- 导入的数据仅保存与展示，不执行其中的脚本、HTML 或技能指令。
- 迁移接口依托宿主认证与可信本地操作入口，校验请求来源；不能仅因普通读取接口可访问，就允许无保护地导出隐私或替换资料。
- 导出白名单不包含凭证，但用户正文可能自行记录敏感信息，不能承诺资料包绝对不含秘密。

### 6.3 模块组织

建议新增独立的资料迁移模块，负责：

- 收集、校验和打包五类资料。
- 预检与生成导入摘要。
- 备份、替换和回滚。
- 对接设置页与本地接口。

复用既有的资源路径、数据校验和技能存档能力，不新增会话迁移、事件数据库迁移或通用备份框架。新增路由、布局与限制继续集中到现有资源规格中维护。

## 7. 验收标准

### 正常场景

- 旧电脑导出、新电脑导入，五类资料完整一致。
- 日记正文、技能历史和账本记录不被截断或重写。
- 默认个人资料在新电脑可访问，不依赖旧电脑绝对路径。
- 通用偏好按白名单恢复，自动采集与主动投递不被隐式开启。
- 已有数据时明确提示替换，并生成可恢复备份。
- 重复导入不重复记账、不增加技能版本。

### 边界与失败场景

- 显式空集合正确替换；必需分类缺失则拒绝。
- 损坏包、未知版本、非法业务数据和不安全路径在正式写入前被拒绝。
- 空间不足或备份失败不改变现有资料。
- 任一类写入失败能恢复导入前的数据。
- 中途退出后可识别并恢复未完成事务。
- 并发写入不会产生余额与账本不一致或旧缓存回写。
- 迁移前后，范围外的会话、事件、工作区、社交和定时任务保持不变。
- 至少验证不同 home 路径，以及 macOS 与 Windows 路径兼容。

## 8. V1 不做

- 完整电脑或 DSH 环境搬家。
- 聊天记录、事件记忆和任务恢复。
- 多设备同步、增量备份和云存储。
- 分类勾选、逐条合并、冲突编辑器。
- 凭证保险库与登录态迁移。
- 自动复制自定义外部目录。

最终产品承诺：**带走大肥鱼的养成资料，选择一个包、一次确认恢复；不搬运行环境，不隐式执行动作。**
