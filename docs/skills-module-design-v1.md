# 大肥鱼 · 活动技能框架 V1（官网主页运营试点）

日期：2026-11-07。根据最新要求修订：**不设置授权状态，先搭建通用框架，第一个试点是大肥鱼自己的官网主页运营。** 本文件替代先前的贴吧试点方案。

## 1. 产品定位

技能是大肥鱼开展活动时可以按需读取、使用和完善的方法。框架不决定她必须做什么，不要求每次活动汇报，也不负责定时唤醒。

```text
主人输入 / 自身状态记录
  → 大肥鱼自主决定活动
  → 发现并读取技能
  → 使用已有工具实际做事
  → 观察结果
  → 记录经验 / 修订指南
  → 下次使用改进后的技能
```

本版不引入授权状态、审批队列、逐次确认、发布额度配置或授权管理页面。按最新要求，整个插件的私有 HTTP token 和工具 preset／会话访问门禁已移除；`skills.enabled` 仅保留模块总开关。DSH 宿主认证、外部服务连接凭证与社交消息目标绑定保留。能访问 DSH 服务地址的客户端可以读取或修改插件数据。

技能内容不是系统指令，也不改变运行环境原有规则。没有配置的网址、源码或发布环境要如实说明，不能把「不用授权状态」理解成「缺少环境时也能发布」。

## 2. 本次框架范围

### 已纳入第一切片

- 通用技能目录与固定 id。
- 按需读取指南、经验与历史版本，有界分页。
- 自主记录经验、自主修订指南，立即保存，无审批步骤。
- 不可变历史快照、版本冲突检测、回退为新版本。
- 全局工具接入、模块开关、统一资源路径。
- 侧边栏「技能」只读页面与无私有 token 的读取接口。
- 技能库不内置任何技能：目录完全由本地已创建技能组成。
- 本地核心、工具与宿主接线模拟测试。

### 不在第一切片

- 官网自动部署器、浏览器驱动或 CMS 接口。
- 技能 UI 编辑、回退或其他写入 API。
- 技能市场、模型自动安装代码、任意上传技能。
- 额外 Agent、活动调度器、ABS 行动选择或计分改动。
- 真正官网的编辑、上线或数据分析；这些依赖具体官网环境。

第一切片完成表示“知识与学习框架已接好”，不代表“官网已上线或已交给大肥鱼运营”。

## 3. 技能模型

每个技能由本地 `create` 写入 id、名称、简介与首版指南。实例化后包含：

| 内容 | 用途 |
|---|---|
| `guide` | 当前有效方法，可由大肥鱼自主修订 |
| `experiences` | 经验条目，含观察、来源与时间 |
| `revision` | 单调递增版本，用于比较与并发更新 |
| `snapshots` | 完整历史，包括指南和经验，支持读取与回退 |

经验统一标记 `observed`，表示记录了观察，不代表框架验证了结论。引用可以为空；网页链接、日志标识只是可追溯来源，不自动变成“已验证”。大肥鱼可以结合经验自行修订指南，框架不额外调用模型评审，也不把经验自动写进指南。

名称与简介随技能文件一起保存，目录由扫描存储得出；大肥鱼可以自己 `create` 新技能，再用 `record/revise` 完善，不需要改代码或重新打包。新增想法只是新增一个技能文件。

## 4. 模型可见接口

### `fish_skill`

- `list`：列出技能简介、当前版本、章节入口。
- `read`：读取指定技能的 `guide`（默认）或 `experiences`，可指定历史版本。
- `history`：读取修订摘要、时间、理由及回退来源。

### `fish_skill_learn`

- `record`：保存经验与可选来源引用。
- `revise`：提交完整新指南、理由和 `expectedRevision`。
- `rollback`：以历史版本的指南和经验创建新版本，保留所有已发生的历史。

常见调用：

```json
{"action":"list"}
{"action":"read","skillId":"homepage-operations"}
{"action":"record","skillId":"homepage-operations","claim":"本次主页构建成功不代表线上正文已更新，仍需检查线上页面。","evidenceRefs":[]}
```

`read` 的 `nextOffset` 非空时还没有读完；后续读取应携带同一个 `revision`，避免跨页时内容变化。修订完整正文前应先读完旧版本，不能把第一页当作全文覆盖。

读取和学习工具分开，避免误用只读工具修改数据。结果用 `{ok,data}` 或 `{ok:false,error:{code,message}}` 表达；写入成功只表示技能知识已保存，不表示网站动作完成。

## 5. 发现与上下文成本

工具描述只说明“技能库没有预置内容”，用 `list` 发现本地已创建技能，按需 `read`。不改人格、不把所有指南塞进 system prompt，不另外搭建技能搜索模型。

工具结果沿正常会话日志保存；读取结果带版本。旧会话中的旧内容不被悄悄替换为新版本。每次新活动可重新读取最新版本。

验证中记录新增工具 schema 字节数；真实首轮 token 增量需要同一模型的 tokenizer/真实会话计量，未测量时不作 token 优化结论。

## 6. 存储与一致性

实现组织：

- [模块装配](<../src/skills/index.js>)：模块启停、全局工具注册与卸载清理，不检查调用会话身份。
- [模型工具](<../src/skills/tools.js>)：参数与结构化输出。
- [技能核心](<../src/skills/core.js>)：目录、读取、记录、修订、回退与持久化。
- 技能目录：扫描 `<skills>/` 下已创建的 JSON 文件。
- [资源规格](<../src/resources/spec.js>)：统一目录、默认开关与限制。

拟运行位置（不在源码目录写运行数据）：

```text
$DSH_HOME/chonkyfish/skills/
  <skillId>.json
```

每个技能一个有界 JSON，保存完整快照序列。`create` 写入第 1 版；此后 `record/revise/rollback` 追加新版本。目录里没有文件就是没有这个技能，不存在由代码补出来的初始版本。

- 同一进程内、同一目录写入串行化；多个 service 实例共享写队列。
- `revise/rollback` 要求 `expectedRevision`；冲突须重读后再合并。
- 临时文件写完并同步，再原子替换目标文件；不把半写 JSON 当成成功。
- 限制文件字节、版本数量、经验数量、单条内容和返回长度；到上限拒绝，不自动丢弃历史。
- 非法 JSON、非法状态、越界路径、符号链接或硬链接拒绝读取/覆盖，不静默重置。
- 只支持单进程管理一个目录，不声称具备跨进程锁、对抗外部目录替换的完整隔离或断电级数据库事务。
- 技能内容不保存凭证、主人私聊和敏感资料；通用文件工具全权限意味着该库不是防篡改安全边界。

V1 默认上限：64 个版本、128 条经验、512 KiB 状态文件、16,000 字符指南；指南每页默认 2,000、最多 8,000 字符；条目每页默认 10、最多 50。经验同样生成版本，因此实际可记录数同时受版本和总字节限制。第一切片没有归档工具，达到上限需要后续维护，不应靠静默删历史解决。

## 7. 示范技能：大肥鱼自己的官网主页运营（自建，不随插件分发）

### 意图

这不是替任意商业客户维护网站的通用代理，而是大肥鱼经营自己的公开主页：介绍自己、展示作品和近况、修正过时信息，形成自己的表达方式。

### 活动类型

1. **认识主页**：了解当前内容、访问入口、源码或 CMS、部署方式和受众。
2. **发现更新点**：检查自我介绍、能力描述、作品展示、近期动态、失效链接。
3. **内容创作**：写新近况、整理作品简介、调整栏目文案，保持大肥鱼的口吻。
4. **维护与验证**：核对事实、预览页面、检查移动端和可访问性、运行现有测试和构建。
5. **发布与检查**：在具体官网接入后按真实部署流程操作，检查线上地址与实际内容。
6. **运营复盘**：只依据可观察的反馈调整内容，不编造浏览量、用户评价或转化效果。

可以自主发现维护点，不需要等主人每次逐项派任务；没有值得更新的内容时也可以保持原样，不为活动频率制造内容。

### 结果区分

| 状态 | 说明 |
|---|---|
| 草稿 | 文案已生成，未修改页面 |
| 本地变更 | 已修改源码或内容，未证明构建成功 |
| 构建/预览通过 | 已验证本地结果，未证明线上已更新 |
| 已发布并核验 | 真实发布结果及线上内容均已核验 |
| 未知/失败 | 如实保留失败原因，不重复盲目部署 |

技能版本回退不是网站回滚，两者必须分开。

## 8. 与现有系统的关系

- 主会话继续自主决策，ABS 只描述内部状态。
- 技能加载/修订不计为探索成功或社交成功。
- 日记记录感受，技能记录可复用方法。
- 技能库通过正常工具系统提供，不限制 preset、工作区或会话；不自动把技能经验注入其他会话。
- 现有资源配置增加 `skills.enabled`，默认 true，调用时重读；关闭后不再提供技能工具操作。
- 已新增技能只读页面；不新增定时任务或修改 persona。安装以管理器结果为准。

## 9. 验收与后续

### 第一切片验收

- 工具可以 `create` 本地技能并 `list` 发现，正文按需加载且可完整分页读取。
- 可以记录观察、自主更新指南和回退；重启后内容一致。
- 冲突不覆盖、损坏不重置、超限不丢历史。
- 无授权状态、审批参数和审批流程。
- 不同 preset、工作区、子会话与直接调用均可使用；停用和卸载后不可执行，部分注册失败能清理。
- 新文件进入包发布清单，测试进入项目总回归。

### 第二切片：真实官网接入

明确网站环境后，完成一次小范围真实运营闭环：读取现状 → 自主提出并执行更新 → 本地验证 → 真实发布核验 → 保存一条有来源的经验 → 下次使用。

管理 UI、内容排期和更多技能可以后续补充，先证明这一条完整闭环，不先建设大型平台。
