# 双客户端输入隔离修复计划

**目标：** 主人持续使用自己的手柄或键鼠控制主机；大肥鱼通过原生 LAN 独立控制 farmhand，不激活窗口、不读取主人的设备输入。

**已确认原因：** 最近 DSH 会话存在调用 SetForegroundWindow 与全局 Alt 的 pwsh 工具调用。游戏适配器仅失焦时屏蔽物理输入，前台、标题菜单和租约释放阶段存在隔离缺口。

- [x] DSH：针对配置原生陪玩能力的大肥鱼及其子任务，在工具执行前实施能力约束；阻止任意脚本/桌面自动化绕过原生 MCP，不依赖脚本正文黑名单。
- [x] 游戏：默认关闭、明确开启的 AI 专用进程输入隔离，覆盖真实设备读取、前后台、标题菜单及世界生命周期；原生行为仍需精确 farmhand 租约。
- [x] 先运行能复现缺口的失败测试，再修复并运行对应回归。所有构建禁用自动部署。
- [x] 自我检查及独立 review；修复所有影响目标的问题后再次检查。
- [x] 使用独立数据目录和存档副本，验证原生 LAN、两角色并行动作、焦点连续不变、输入不串控。世界退出后的输入隔离与失效租约由实际安装程序集测试覆盖。
- [x] 真实手柄核验单独记录。自动生成的输入不能替代主人真实手柄操作验收。
- [x] 未运行正式 Mods 的游戏进程时部署已验证 DLL/config 与技能；测试进程仍从隔离 Mods 运行。记录最终证据和需重新加载的部分。

2026-11-16 验收：USB Xbox 360 兼容手柄，24 次 AI 后台原生移动全部完成；60.491 秒区间中主人有 1,476 个实体手柄输入采样，AI 看到手柄的采样为 0，938 个更新同时观察到双方角色执行动作。主人确认“正常，没有抢窗口或手柄”。另有 61 次效果验证成功的挥斧；下一棵树不可达时正常拒绝，未强制改变目标。
