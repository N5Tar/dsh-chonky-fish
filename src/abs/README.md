# ABS：自身精神状态审查（self-review slice）

本切片按用户要求改变了决策权归属：**ABS 不再生成动机、挑选渠道、评分候选或给 Agent 派任务。** 它只维护内部状态数值，把状态渲染成一段自然语言「自身精神状态审查」，交给大肥鱼自己的会话；是否行动、做什么、通过什么能力做，由大肥鱼在它的正常推理中自己决定。

旧的“ABS 选行动 → 注入任务 → 执行”链路已退出运行时，相关状态在升级时归档。代码测试均为离线，不代表真实模型、搜索或 GUI 已联调。

## 闭环

```text
真实事件（主人发言 / 严格关联的搜索工具结果）
        │
        ▼
ABS 状态更新（社交 / 探索满足度）
        │
        ▼
自然语言「自身精神状态审查」
        │  （active 模式才投递）
        ▼
大肥鱼会话获得一次内部状态记录
        │
        ▼
大肥鱼自己决定：行动、使用工具、或保持安静
        │
        ▼
真实结果再次进入观察（只认客观事实）
```

ABS 只回答“我现在处于什么状态”；“我要做什么”不在 ABS 里。

## 审查文本规则

- 正文改为大肥鱼第一人称的内心独白，用“唔……我有一点想……”表达感受，不再输出分项状态报告、数值、JSON 或审查标题。
- 保留原有五档缺口边界；社交与探索分别表达意愿强弱。满足时不强造意愿，状态缺失时承认不清楚。
- 有上次审查才描述念头变强、变淡或相近；真实交流与探索结果仍保留现实时间，不捏造回忆、经过时长或主人是否有空。未知探索结果不宣称完成，拿到资料不等于学会。
- 可以表达愿望、提出开放的自问，也可以暂时不做；**不指定**任务、渠道、工具或下一步，不要求联系主人。
- 由确定性模板渲染，不额外调用模型“润色心理活动”；只改表达，不改需求公式、反馈、权限、调度或已有状态。
- 文本带有 `【大肥鱼的内心独白 · 非主人发言】` 来源行。它是角色化的内部上下文，**不是模型原生 reasoning**；不伪造 thinking 标签或模型历史推理。
- 实验台栏目仍称“自身精神状态审查”，预览与实际投递共用这份独白模板。

渲染实现见 [review.js](<review.js>)，回归见 [run-review.mjs](<tests/run-review.mjs>)。

## 投递语义与已知限制

active 模式下，一次到期的审查通过 `followup` 以 `role: 'user'` 进入**面板当前绑定的主人会话**，来源标记仍为 `chonkyfish-self-review`。第一人称独白不改变消息角色：它是模拟内心独白的内部上下文，不是主人发言，也不会被事件引擎当成主人事实抽取。

必须区分：

- **审查已接纳**：消息进入会话队列并持久化，不等于模型已理解；
- **大肥鱼已经回复**：会话里出现一轮输出，不等于主人已读；
- **主人已经看到/回复**：只有主人真实发言才是客观互动事实。

**当前宿主限制**：向会话投递内部记录会启动一轮正常模型推理，因此通常会产出一条会话回复；ABS 不规定回复内容，也**不能保证“完全不说话”**。为避免刷屏，除审查间隔外还有**现实时间最小间隔**（默认 10 分钟），与倍率无关。若后续要支持“完全静默的感知”，需要独立的内部会话或宿主静默轮次能力，尚未实现。

投递失败（无绑定会话、会话未运行、正在处理其他输入、身份不匹配、持久化未确认）都会如实记录为失败，不会伪造成功。

## 状态反馈：只认客观事实

满足度只由可观察事实更新，**不采信模型自述**：

| 观察 | 条件 | 效果 |
|---|---|---|
| 主人真实发言 | 鱼鱼会话中 `source.kind === 'user'`（旧日志无 source 按主人处理） | 社交满足度 +0.05 |
| 搜索取得可用资料 | 严格关联 `web_search` 的 `tool/call → tool/result`，真实来源 URL 元数据 | 探索满足度 +0.15 |
| 本地阅读 / 图片查看 | 严格关联成功回执；`read` 的非空行元数据，或 `read_image` 的非空图片附件 | 探索满足度 +0.15，每轮本地活动最多一次 |
| 工作区创作 / 修改 | `write` 的创建回执及非空内容，或 `write/edit` 的实际差异元数据；限定鱼鱼工作区 | 同上，与阅读共享每轮上限 |
| 搜索完成但无内容 / 执行失败 | 同一严格关联 | 记录事实，满足度 +0 |
| bash 成功 / 无证据的本地结果 | 命令成功不等于取得收获，不猜测命令含义 | 记录未验证，满足度 +0 |

本地证据以工具类型、路径和内容的 SHA-256 摘要去重，跨重启生效；相同证据不重复奖励，ABS 自身状态目录不参与。使用原有 `explorationGain`，不增加新的增益参数。这只是“取得内容 / 发生实际变化”的客观代理，**不宣称模型学会了知识或作品质量合格**。没有验证器的任意 shell 活动暂不计分。

实验台新增「满足度变化账本」：记录现实时间、变化原因、变化前后满足度、实际增减百分点（考虑 0–1 截断）；自然衰减单独记账，未加分也展示原因。状态保留最近 200 条，界面显示最近 40 条。衰减在服务结算时记录，不是每秒采样。旧活动不补记、不补分；升级不会重置数值或修改倍率。

去重键为 `kind:sessionId:seq`，重启后不重复计分。会话里 ABS 注入的审查旁白、主动消息、定时提醒、系统注入、助手回复都不会被当成主人互动或探索结果。

## 模式

| 模式 | 行为 |
|---|---|
| `off` | 不安排审查；仍可观察真实事件并记录 |
| `shadow`（默认） | 计算状态、在实验台生成审查预览，**绝不投递** |
| `active` | 允许投递审查；需要界面显式确认；启用后先经过冷却期 |

模式与时钟暂停不同。`0×` 冻结 ABS 时间并阻止新的投递；`off` 只是不安排审查。

## 每日休息（静默时段）

默认启用 **23:00–次日 08:00（UTC+8）**，按现实时间执行，不受 `timeScale` 影响。开始时刻包含在内，结束时刻不包含；支持跨午夜及同日时段，起止相同视为无效配置。

- 休息期间 ABS 不投递审查，不唤醒会话；手动触发及切换 active 也不能绕过。预览仍可查看。
- 定时器只做轻量配置检查，不每隔几秒生成审查/审计；休息结束后只进行一次当前到期审查，不补发夜间积压。
- 调度预估会把落在休息时段内的审查顺延至结束时刻；启用冷却、暂停和正常间隔仍然生效。
- 投递前及异步解析会话后均检查休息门禁，避免 23:00 边界竞态。
- 不取消已投递的会话轮次、不打断正在进行的工具、不阻止主人主动聊天；满足度衰减和真实反馈继续沿用原规则，休息不自动加分。
- 此设置只约束 ABS，不修改其他插件或用户创建的定时任务。
- 实验台可查看当前是否休息、恢复时间，调整开关和起止时间；修改必须点击应用。保存配置本身不立即投递。

配置为 `abs.restHours: { enabled: true, start: "23:00", end: "08:00" }`。旧配置未提供该字段时使用上述默认值；不用重置任何已有状态。通用配置清洗遇到无效时间会回退默认值，专用管理接口严格拒绝无效输入。

## 时间倍率

对大肥鱼和实验台，**只有现实时间**，统一以 UTC+8 显示。审查中的交流/探索事实、近期活动、最近反馈、上次投递和下次审查均使用真实时间戳；缺少真实时间的旧记录不冒用计算时间。审查不展示第二套时钟。

`abs.timeScale` 默认 **1**，范围 0–120，支持小数。倍率只表示状态变化及审查节奏的速度：60× 下，现实一分钟累计相当于默认速度一小时的变化；0× 暂停自然变化与新的投递，不暂停现实时间。底层保留分段累计量与旧字段，以兼容已有状态和连续调速；这是计算实现，不是大肥鱼感知的另一种时间。原始技术详情与导出仍保留这些诊断字段。

- 分段锚点 `ABS = virtualAt + (realNow - realAt) × scale`；调速先结算旧倍率再建新锚点，切回 1× 不会重置已累计时间。
- 系统时间回拨时冻结在真实水位，不倒退、不重复累计。
- 重启按保存倍率计入停机时间，但只做当前一次审查，不补发错过的审查。
- 倍率在服务串行边界应用；界面区分“已保存配置”和“当前已应用倍率”。

审查间隔是 **ABS 分钟**（默认 120，限制 10–120）；现实最小间隔是 **现实分钟**（默认 10），用于防止高倍率下刷屏。两者含义不同，不要混用。

## 配置

配置仍走现有资源管理 `/chonkyfish/config` 的 `abs` 顶层键，经清洗与深合并：

```json
{
  "abs": {
    "mode": "shadow",
    "timeScale": 60,
    "restHours": { "enabled": true, "start": "23:00", "end": "08:00" },
    "reviewIntervalMinutes": 120,
    "reviewMinRealGapMinutes": 10,
    "activationCooldownMinutes": 60,
    "feedback": { "ownerMessageGain": 0.05, "explorationGain": 0.15 },
    "drives": {
      "social": { "initialSatisfaction": 0.55, "setpoint": 0.75, "decayPerHour": 0.008 },
      "curiosity": { "initialSatisfaction": 0.35, "setpoint": 0.70, "decayPerHour": 0.004 }
    }
  }
}
```

数值参数由 [config.js](<config.js>) 统一提供。策略版本 `abs-self-review-v1`。

## 本机管理接口

单一路由 `/chonkyfish/abs`，无插件私有鉴权、无需 `x-chonkyfish-token`。DSH 宿主认证仍由宿主管理；可达此接口即能执行以下操作，请勿无保护地对公网开放。目标会话绑定、active 确认、每日休息与输入/体积校验均保留：

- `GET/HEAD`：状态（含当前审查预览）、感知条件、最近 100 条审计。
- `POST {action:"preview"}`：只返回审查文本，不投递、不改状态。
- `POST {action:"wake"}`：按当前 ABS 时间与模式执行一次审查；active 且到期时会真实投递。
- `POST {action:"mode",mode:"off"|"shadow"|"active",confirmActive?:true}`：切换模式；active 必须确认。
- `POST {action:"time-scale",timeScale:60}`：应用 0–120 的有限倍率，不触发审查。
- `POST {action:"rest-hours",enabled:true,start:"23:00",end:"08:00"}`：设置每日休息；UTC+8，拒绝非法或相同起止时间，保存不立即投递。
- `POST {action:"replay",hours:72}`：隔离投影未来状态与审查文本，不探测、不投递、不调用模型。
- `POST {action:"export"}`：最多 1000 条近期审计的 JSONL。
- 不提供任意 Observation/回执注入、任意会话执行或直接发送接口。

## 持久化与恢复

`$DSH_HOME/chonkyfish/abs/state.json` 是状态、反馈去重键、审查记录与时钟的权威；`audit.jsonl` 是有界诊断记录，最终一致，不实现跨库强事务。写入串行、原子替换并 fsync；损坏状态拒绝启动，不静默清空。

升级迁移：旧版 `motivations` / `executions` / `proposalIds` / `history` 会归档为一条 `StateMigrated` 审计并清空；需求数值、反馈去重键和时钟保留。旧版执行不再有“未决执行重试”语义。

仅支持同一目录单进程写入。审计保留最近 2000 条 / 8MiB；观察记录 200 条；反馈去重键 10000 条，达到上限失败关闭而不驱逐。

## 尚未接入

- 没有 ABS 侧的行动、渠道或联系人选择——这是本切片的设计目标，不是缺失。
- 没有让大肥鱼“完全静默感知”的内部会话；投递仍会启动一轮正常会话推理。
- 没有邮件、QQ、贴吧等专用投递/读取 Adapter； QQ 按用户决定不在本期。
- 没有完整分层研究抽样、标注与基线对照；不能据当前审计宣称实验校准完成。
- 真实模型、搜索、宿主 GUI 尚未联调；离线测试不替代真实闭环证据。
