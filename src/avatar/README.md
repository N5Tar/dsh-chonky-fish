# 虚拟形象模块

大肥鱼常驻 GUI 右下角的眨眼形象，通过 `shell.overlay` 增量挂载，不替换任何现有面板。

## 素材与播放

原始素材由用户提供：`dsh_blink_fast_hold3s.gif`，362 × 362，共 8 帧。前 7 帧各 30ms，最后一帧为睁眼待机，原始停顿 3000ms。

- `assets/original.gif`：原始文件副本；源文件不修改。
- `assets/blink-00.webp` 至 `blink-07.webp`：解码合成后的无损透明帧，画布完全一致。
- `assets/manifest.json`：原图 SHA-256、尺寸、原始帧时长及待机配置。
- `assets/idle-preview.webp`：最初上传的静态预览，仅留作参考，不参与播放。
- `prepare.py`：使用 Pillow 从原始 GIF 提取帧；遇到不同的时间结构时拒绝猜测。

这份素材只有 8 帧，因此采用帧序列，避免浏览器重播 GIF 缓存问题，也能可靠去掉原有的固定停顿。构建时将无损 WebP 嵌入 Client，无额外网络请求。全部帧加载解码完成后才启动动作。

循环：第 7 帧静态待机 → 独立均匀随机等待 2000～5000ms → 依次播放第 0～6 帧（各 30ms，共 210ms）→ 回到第 7 帧，再随机等待。后台浏览器调度可能延后动画，不强制补播。

## 窗口行为

- 桌面 144 × 144px，右下边距 16px；窄窗口 104px，边距 12px，兼容安全区域。
- 无背景卡片，角色保留透明底；形象本身鼠标穿透，只有隐藏/恢复按钮接收操作。
- 低层级 overlay，按宿主层级让位给菜单、对话框及提示；正式布局仍需浏览器视觉验收。
- 点击 × 暂时隐藏，保留小恢复按钮。切换面板不卸载形象；刷新后恢复默认显示。
- 页面进入后台、隐藏形象、系统要求减少动态效果时，取消动画计时并恢复待机帧；允许播放后重新随机等待。
- 卸载时清除定时器、媒体查询及页面可见性监听。

## 代码与验证

- `player.js`：可注入时钟与随机源的播放器。
- `widget.js`：React 全局挂件，资源预加载、可见性处理和隐藏控制。
- `tests/run-player.mjs`：覆盖随机边界、原始动作节奏、暂停恢复、销毁与资源完整性。
- `build.mjs` 构建 Client；`npm run test:avatar` 验证此模块。

素材来源为用户提供，仅在此插件中使用；未引入第三方图片。
