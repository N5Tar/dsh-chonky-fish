# 虚拟形象模块

大肥鱼常驻 GUI 右下角的眨眼形象，通过 `shell.overlay` 增量挂载，不替换任何现有面板。

## 素材与播放

当前使用用户提供的“小蓝鲸”成品素材，位于 `assets/avatar/random/`。41 张透明 PNG 均从成品包原样复制，没有重绘或重新裁剪；每帧时长读取对应 GIF。`manifest.json` 保存尺寸、SHA-256、帧时长、动作权重和循环范围。

| 动作 | 循环次数 | 随机权重 |
| --- | --- | --- |
| idle 待机 | 2～4 | 3 |
| running 工作 | 2～3 | 2 |
| waiting 等待 | 2～3 | 2 |
| review 思考 | 2～3 | 2 |
| waving 挥手 | 1 | 2 |
| jumping 跳跃 | 1 | 2 |
| failed 失落 | 1 | 0.5 |

显示 idle 第 0 帧，随机停顿 2～5 秒 → 按权重选动作（排除上一次动作）→ 随机选择该动作循环次数 → 按半速播放（`playbackRate: 0.5`，每帧显示时间为原始时长的两倍） → 回到待机停顿。没有聊天事件绑定、业务状态机、桌面移动或鼠标跟随。失落仅是随机表情，不表示实际任务失败。

帧画布均为 192 × 208，构建时嵌入 Client，全部解码后启动播放。后台恢复时重新等待，不补播被打断的动作。旧眨眼素材保留在 `assets/avatar/`，不再纳入当前客户端。

重新导入：`python3 app/dsh/ui/avatar/import-random.py /path/to/Downloads`，需要 Pillow 及 `final-and-qa-5-*`、`final-and-qa-6-*` 两个用户素材 ZIP。`prepare.py` 仅用于旧眨眼素材。

## 窗口行为

- 桌面 144 × 144px，右下边距 16px；窄窗口 104px，边距 12px，兼容安全区域。
- 无背景卡片，角色保留透明底；形象本身鼠标穿透，只有隐藏/恢复按钮接收操作。
- 低层级 overlay，按宿主层级让位给菜单、对话框及提示；正式布局仍需浏览器视觉验收。
- 点击 × 暂时隐藏，保留小恢复按钮。切换面板不卸载形象；刷新后恢复默认显示。
- 页面进入后台、隐藏形象、系统要求减少动态效果时，取消动画计时并恢复待机帧；允许播放后重新随机等待。
- 卸载时清除定时器、媒体查询及页面可见性监听。

## 代码与验证

- `player.js`：可注入时钟与随机源的播放器。
- `widget.js`：React 全局挂件，资源预加载、可见性处理和隐藏控制。
- `tests/run-player.mjs`：覆盖七种动作、循环上下界、原始帧时长、相邻动作去重、暂停恢复、销毁与资源完整性。
- `build.mjs` 构建 Client；`npm run test:avatar` 验证此模块。

素材来源为用户提供，仅在此插件中使用；未引入第三方图片。
